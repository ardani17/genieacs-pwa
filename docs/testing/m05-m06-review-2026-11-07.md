## Review lanjutan · 8 November 2026

Review Standards dan Spec diperiksa ulang secara independen terhadap keadaan
akhir lokal, termasuk seluruh remediation yang belum dipublikasikan. Tiga temuan
tambahan direproduksi sebelum perbaikan:

### Standards

**1 temuan P2, diperbaiki.** Sinkronisasi prop CodeMirror memakai `setValue`,
yang memicu callback edit dan mengganti source dengan mask ketika disembunyikan.
Form bersih ikut menjadi dirty dan reveal berikutnya menghilangkan draft.
Wrapper kini mengabaikan origin `setValue`; reveal tetap memeriksa izin server,
tetapi mempertahankan draft dirty beserta baseline revisinya. Tes memakai
CodeMirror sebenarnya, dan tes UI/browser menguji hide/reveal draft.

### Spec

**2 temuan, diperbaiki:**

- **P1:** Sesi CWMP yang berakhir setelah Inform belum membuktikan task
  dijalankan. Executor sebelumnya melaporkan sukses bila tidak ada fault dan
  expiry belum lewat, meskipun task masih tersimpan. Probe Mongo kini memastikan
  task sudah dikonsumsi sebelum status `done`; task yang masih antre tetap
  `pending`/`unknown` dan dibersihkan tanpa replay. Regresi dengan task Mongo
  sungguhan sebelumnya gagal (`succeeded`), lalu lulus (`unknown`).
- **P2:** Container konfigurasi mengabaikan filter native. Renderer kini memakai
  pemeriksaan keberadaan field dan evaluator native sebelum merender. Regresi
  mencakup filter literal false, ekspresi yang tidak cocok dan yang cocok.

Pemeriksaan ulang kedua reviewer tidak menemukan temuan terbuka pada perbaikan
tersebut. Tes regresi frontend terarah **17/17 PASS**; executor **23/23 PASS**.

Run penuh lanjutan: backend **115/115**, profil **52/52**, frontend **105/105**,
integrasi firmware **9/9**, scoped users **6/6**, config masking **5/5**,
semuanya PASS. Formatting, ESLint, TypeScript, config coverage dan build
produksi engine/web juga PASS. Tes browser dan CI exact-head dilanjutkan setelah
snapshot ini; hasil final dicatat pada PR #8.

Preview pengguna berada pada Compose project `genieacs-pwa-preview`, terpisah

Standards lanjutan: 1 temuan (P2), terselesaikan. Spec lanjutan: 2 temuan

### Gate keamanan pada publikasi lanjutan

Run browser lokal final **129/129 PASS**. CI pada `bb5f8ed` meluluskan verify
dan e2e, tetapi security gate menahan alert baru **81**,
`js/user-controlled-bypass`, pada otorisasi di dalam kondisi binding WAN.
Pemeriksaan sumber tidak membuktikan mutasi tanpa izin karena mutasi juga ada di
dalam kondisi itu. Pemeriksaan izin tetap dipindahkan ke batas fase setelah
refresh agar selalu berjalan sebelum keputusan instance/binding dari form.
Pembacaan perangkat kini juga memakai izin terbaru dan berhenti bila perangkat
keluar dari cakupan.

Regresi pencabutan izin mencakup binding yang sudah cocok dan binding yang perlu
diperbaiki. Sebelum perbaikan, kasus binding cocok masih masuk fase verify
setelah izin dicabut; assertion fase gagal. Mapping alert 81 hanya mencatat
perbaikan source untuk diverifikasi ulang oleh CodeQL, tanpa exception baru.

CodeQL pada `5e2a2ba` mengonfirmasi alert 81 `fixed` pada ref PR. Gate masih
menolak karena registry runtime `ALERT_MAPPING` belum memiliki entri 81,
meskipun dokumen evidence sudah memilikinya. Registry dilengkapi dengan paket,
tes dan disposition source fix yang sama. Regresi evaluator menolak alert 81
yang masih open dan menerima fixed hanya bersama analisis exact-ref/SHA yang
sukses; seluruh aturan gate dan exception tetap berlaku.
