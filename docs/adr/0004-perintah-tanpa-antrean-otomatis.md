# Perintah perangkat tanpa antrean otomatis

Rilis awal tidak menambahkan antrean otomatis untuk perintah perangkat yang
gagal dijangkau. Aplikasi melaporkan hasil dan error secara jelas beserta log
diagnosis; pengguna mengirim ulang secara sadar. Antrean yang menunggu Inform
berikutnya memerlukan keputusan terpisah tentang masa berlaku, pembatalan,
otorisasi, serta hasil eksekusi dan belum termasuk keputusan saat ini.
