# Security Policy

## Supported Versions

This project tracks upstream GenieACS and adds PWA/VPN extensions. Only the
latest minor line receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| < 1.2   | :x:                |

## Reporting a Vulnerability

Please report vulnerabilities through
[GitHub's private vulnerability reporting](https://github.com/ardani17/genieacs-pwa/security/advisories/new)
rather than opening a public issue.

- Include reproduction steps, affected endpoints or files, and impact assessment
  where possible.
- You can expect an acknowledgement within a few days.
- If the report is accepted, a fix will be prepared and credit offered in the
  advisory. Coordinated disclosure happens after a patched release is available.
  Declined reports receive a short explanation.

Vulnerabilities in upstream GenieACS itself should also be reported upstream at
<https://genieacs.com>.
